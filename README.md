# YagYz-Notpad

CustomTkinter arayüzü ve Fernet şifreleme kullanan basit bir not defteri uygulaması. Notları şifreleyerek `.txt` dosyalarında saklar.

## Özellikler

- Şifreli giriş ekranı (Varsayılan şifre: `12345`, Enter tuşu destekli)
- Notları Fernet ile şifreleyip kaydetme
- Yeni dosya oluşturma
- Çıkış yap / oturumu kapat butonu

## Kurulum ve Çalıştırma

Gerekli kütüphaneleri yükleyin:

```bash
pip install customtkinter cryptography
```

Uygulamayı başlatın:

```bash
python notpad.py
```
